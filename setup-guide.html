Connecting Salesforce & Gong to Claude Desktop

Connect Claude Desktop to Salesforce and/or Gong so Claude can access your data directly.

What you need before starting

ToolKey to request
SalesforceSalesforce MCP Token
GongGong API Key

To get your keys, reach out to Shubhi Maheshwari (smaheshwari@netchexonline.com) or Pranav Mankar (pmankar@netchexonline.com).

Step 1 — Install Node.js

1

Download and install Node.js

Go to nodejs.org in your browser.

Click the large button labelled “Download Node.js (LTS)” — LTS is the stable, recommended version.

Open the downloaded file and follow the installer: Continue → Continue → Continue → Install.

Enter your computer password if prompted, then click Close when done. Node.js runs silently in the background — you do not need to open it.

Windows: when the installer reaches the “Destination Folder” screen, click Change and set the install path to somewhere with no spaces — e.g. C:\nodejs instead of the default C:\Program Files\nodejs. This avoids a known Windows issue where MCP servers fail to start with a 'C:\Program' is not recognized error.

Step 2 — Open Claude Desktop Settings

2

Get to Settings

Mac: Click your profile icon or name at the bottom-left of Claude → select Settings.

Windows: Click the menu icon at the top-left → Settings.

Step 3 — Go to Developer and click Edit Config

3

Open the config file

In the Settings window, scroll down the left sidebar and click Developer.

Click Edit Config — this opens your config file in a text editor.

Step 4 — Update the Config File

Path A · Use a pre-made config file

Choose the config file that matches your setup:

I want to connect…Use this file
Salesforce onlyconfig_salesforce_only.txt
Gong onlyconfig_gong_only.txt
Both Salesforce and Gongconfig_salesforce_and_gong.txt
4

Replace the config file contents

In the text editor, select all: ⌘A (Mac) or Ctrl+A (Windows), then delete.

Open your config text file, copy all its contents, and paste into the now-empty config file.

Save: ⌘S (Mac) / Ctrl+S (Windows).

OR
Path B · Generate your config from the MCP Config Builder

Prefer this if you want more than one combination, or want to add tools like Highspot alongside Salesforce and Gong.

4

Build and paste your config

  1. Open the MCP Config Builder:
    smaheshwari-nc.github.io/mcp-config-builder →
  2. Check the box next to every MCP you want to connect (Salesforce, Gong, Highspot, or any combination).
  3. Copy the generated config from the box on the page.
  4. Back in Claude Desktop, select all (⌘A / Ctrl+A) in the empty config file, delete, and paste in what you copied.
  5. Save: ⌘S (Mac) / Ctrl+S (Windows).
5

Replace the placeholder text with your actual keys

Find PASTE_YOUR_SALESFORCE_TOKEN_HERE → replace with your Salesforce token.

Find PASTE_YOUR_GONG_API_KEY_HERE → replace with your Gong API key.

Keep the quotation marks on both sides — only replace the placeholder text inside them.

Save the file again.

Step 5 — Restart Claude and Verify

6

Fully quit and relaunch Claude Desktop

Mac: Right-click Claude in the Dock → Quit.

Windows: Closing the window does not quit Claude — it minimizes to the system tray. Right-click the Claude icon in the system tray (bottom-right, near the clock — click the arrow if it's hidden) → Quit, and wait a few seconds for it to fully close. If Claude doesn't reopen properly, open Task Manager (Ctrl+Shift+Esc), find any Claude entries under Processes, and click End Task before relaunching.

Then reopen Claude Desktop.

7

Confirm the connection

Go to Settings → Developer. Your MCP servers should appear with a blue running badge.

Try it out

  • “Show me my top 5 open opportunities in Salesforce”
  • “Summarise my last Gong call with [customer name]”
  • “Which deals are at risk of closing late this quarter?”

Troubleshooting

Server shows ‘failed’

Check that your token/API key is correct — no extra spaces or missing characters. Make sure you kept the quotation marks and only replaced the placeholder text inside them. Fully quit and relaunch Claude Desktop after saving.

Servers not listed at all

Open the config file again (Settings → Developer → Edit Config) and confirm your content is still there. Make sure you saved the file before restarting Claude.

Token expired or invalid

Request a fresh token/key and update it in the config file, save, and restart Claude.

Error mentions ‘C:\Program’ is not recognized (Windows)

This happens when Node.js is installed at the default path C:\Program Files\nodejs — the space in “Program Files” breaks command execution on Windows. Fix: reinstall Node.js and choose a custom install path with no spaces (e.g. C:\nodejs), then fully quit Claude Desktop (see Step 5) and relaunch.
